Implementation notes for Claude Code
Canvas. White workspace; gray card-on-gray removed. Sections are divided by spacing and 1px hairlines. Content max-width is 1320px, centered with 40px gutters, and below 1400px it simply fills the width.
Sidebar. 236px wide, a 40px brand row, 34px nav rows with a 16px line icon at medium weight. The selected state is a soft navy tint with no left bar. Reports and Accounting are grouped under the quiet "Insights" label, and Settings sits below a divider. The org block (logo, Manor's Cremation, staff online) sits at the bottom as the active org rather than a second brand. Routes are unchanged.
Topbar. 56px tall. Search on the left with a ⌘K hint (visual only, unless a shortcut already exists). Audit and Templates stay visible as ghost buttons, with the same routes and auth. Notifications becomes an icon button with the same behavior. New Case is the only filled button. The avatar trigger opens the existing Sign out; no new destinations.
Dashboard. The five existing numbers form one hairline KPI strip. Needs attention collapses to an "All caught up" line at zero, and shows the existing items as rows when there are some. The right column holds the stage pipeline with the same counts and click-through, and zero stages are muted. Activity uses the same events: the case number becomes a chip, actor and time are right-aligned, and rows get a hover.
Stage preview. Clicking a stage row expands an inline preview of the cases already in that stage (case number, name, last updated), using the same data the stage page loads. Clicking again collapses it, and one stage is open at a time. Clicking a case opens Case Detail as today. "Open full stage list →" keeps the existing stage route. No routes change.
Presentation-only label. "Case updated (checklistState)" renders as "Checklist updated", through a display map keyed on the existing label string. No events are filtered.
Currency. Uses the existing formatter if there is one (e.g. Intl en-US). Calculations are unchanged.
Icons. The repo has no icon library, so these are small inline SVG glyphs in one shared Icon component. No new dependency.
Color. Text is a crisp neutral (no warm brown). Navy is for action and selection, green for positive, red only for attention. Font stays Work Sans.
Mobile. The existing drawer is kept, with a hamburger and 44px rows. The KPI strip becomes a 2×2 grid.
