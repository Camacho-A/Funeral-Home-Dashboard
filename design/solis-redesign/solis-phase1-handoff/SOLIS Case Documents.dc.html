Implementation notes
Tabs. All six stay: Overview, Workflow, Billing, Documents, Activity, Schedule. This is the Overview tab.
Next step. Shows the current stage's existing checklist from the Workflow logic, with the same composite keys and gating. "Continue workflow" calls the existing advance action and stays disabled until the checklist is complete.
Header. Name in title case (presentation only), case number, and stage with days in stage. The stage chip uses the full stage name.
Weight. Over 200 lb shows in amber with an "Over 200 lb" tag. Presentation only.
Right rail. Existing case and next-of-kin fields, shown read-only. Editing stays where it is today.
Activity. The latest 3 events for this case from the existing feed. Labels use the Phase 1 display map.
Documents tab. Two groups. Required lists the case's existing required documents with their current status (On file, Signed, Missing). Missing rows get an amber status and a primary "Add" button that opens the existing upload. Other documents lists everything else. The "⋯" menu holds the existing actions (View, Download, Print, Replace, Archive). "Generated" badges are gone, and the nested Documents/Forms/History tabs fold into these groups and the menu.
Mobile. Single column. The rail sits below the next step, and the tabs scroll horizontally.
