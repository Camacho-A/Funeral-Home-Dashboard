Implementation notes
Data. Only existing fields: name, case number, current stage, and the progress % SOLIS already shows. No owner, next action or SLA columns.
Names. Shown in title case through a presentation helper. Stored values are untouched.
Initials. Taken from the displayed name. Neutral navy tint, not color-coded.
Search. Filters by name or case number using the existing search.
Stage ▾. Lists the existing stages and navigates to the existing stage route. Routes don't change.
Status ▾. Include only if SOLIS already has a status field (e.g. active / completed). Otherwise omit it.
Rows. The whole row opens Case Detail as today. The "← Back to Dashboard" link is removed, since the sidebar handles navigation.
Layout. A table with hairline dividers, no card wrapper, and a 1320px max width. On mobile, rows stack, with 44px touch targets.
